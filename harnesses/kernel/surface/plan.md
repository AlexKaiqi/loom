# Plan

Use a plan for work that needs multiple steps. Replace the example with concrete steps and acceptance criteria; leave simple tasks unplanned.

For each completed step, record the actual evidence path and remaining uncertainty before checking its box. A checked box records progress, not independent verification. Keep the first unchecked step current; revise the plan when the objective or evidence changes.
