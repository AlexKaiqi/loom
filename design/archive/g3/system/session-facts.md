# Read-only original Session facility facts

`SessionFacts(snapshots, execution_root, engine)` consumes a trusted existing normal `SnapshotStore`, an unaliased existing X root, and an Engine exposing only `inspect(cid)` and `call("GET", "/volumes/<original-id>", missing=True)` here. It creates no directories, Journal, new state, owner or loop.

`facility(node_request, execution_id, confirmation_request_id, stopped, released)` returns `{owner:"X",kind:"session_execution",execution_id,node_request_digest,confirmation_request_id,session_confirmation:<exact SnapshotStore.query bundle>,original_stopped_response:<unchanged>,original_execution_response:<unchanged>}`. This is explicitly a host projection, not an invented native X response. `read(facility,node_request)` rechecks every original and returns `{frame,binding,bundle,confirmation_request_id}`. R wrappers, full principal/grants/parent selection and stable per-action ID are Runtime responsibilities.

Read actual `Xroot/sha256(execution_id)/record.json` without Journal.get. Check original request digest/schema/session/invocation/source, actual initial channel_write at offset zero (complete canonical Node request plus LF digest/bytes, full call scope and saved original call blob), released=true, STOPPED and nonpending output. Both old responses must retain exact binding/result/non-slot artifacts. Slot snapshots are individually immutable hash-checked and matched to their original reservation tuple; their historical totals need not equal current slots. Final checkpoint must equal current artifact, original S owner source and stopped-proof prepared_ref including full seven-field execution tuple. Its RELEASED retention must have an original S sealed-owner receipt and the retained normal archive must match its bytes/digest; the old X archive may correctly be absent.

Engine current GETs must establish the exact original CID and volume absent. Never issue a mutation. Missing source, ambiguous record, Q, broken tuple/hash or unavailable observation raises `reference_invalid`, never a positive receipt.

Read the original bounded stdout terminal frame and compare to independently parsed confirmed JSONL. Accepted-only is allowed only without an existing original result, with original pi.op.meta/state, lane membership and unique full binding. A result locator uses existing resolve_original for original JSON.stringify result/prefix/range/binding. Its saved boundary must equal the full original stdout frame; absent boundary cannot authorize a decision. A saved result with an exact original paused_reconciliation_required frame can still be returned without losing the result. Runtime does not derive stop/successor policy here.

Preimplementation command: `python3 -B validation/session_facts/run.py --batch NAME`. Missing module means MISSING/0. Four finite groups are preregistered in protocol.json, reusing nine actual prior invocations and explicitly derived file faults. No new Docker execution or model calls. Current Engine absence is read-only evidence; false presence controls are marked simulation.
