# M06：浏览器沙箱环境——性质契约与用例

状态：CONTRACT_DRAFT_2026-09-15。经用户 2026-09-15 授权立项（验收目标澄清：任务沙箱需扩展支持浏览器类环境）。本文件仅建立性质、用例与判据；无实现、无运行、无通过结论。依据：v5 §2/§3/§5.3、`design/g3/x/backend-seam.md`（D-X-ENV-001 T0/T1）、`design/g3/x/contract.md`、`governance/linux-environment.md` 与既有 X/R/F/E/S 契约。

## 1. 目标与非目标

目标：在既有 Runtime/R/E/F/X/S 之上增加一个登记在案的浏览器执行 profile（`linux-browser`），使 Harness 的普通 shell 工具能在任务沙箱内完成固定浏览器场景，产物与动作留痕进入既有证据链。M06 验证的是"环境扩展不破坏既有契约且证据闭合"，不是浏览器自动化能力本身。

非目标：不新增模型可见工具面（仍只有 `shell`）；不实现图像 artifact 回流（`backend-seam.md` §5a 保持未授权未实现）；不做 exposed_ports/VNC；不做 grounding 质量宣称；不引入云端浏览器服务；不改 M01 预算判据。

契约修订说明：本里程碑不新增契约面，但 `environment` 字段从单一常量改为 profile 引用属于 `backend-seam.md` §5 流程下的一次小型契约修订（X request 绑定 + cases.json 增补），必须在实现前完成修订并独立验证；该修订本身不是本文件宣称的"无新增"范围。

## 2. 性质（必须保持）

- **P1 profile 资产化**：浏览器 profile（镜像内容、依赖清单、digest）登记在 R；X 按 profile 校验环境与预算；同一 digest 可复现构建。
- **P2 零新执行入口**：场景仅经既有 shell 工具与 X 契约执行；路由、授权、预算、UNKNOWN/不重跑语义不变。
- **P3 出网受控**：profile 声明的 egress 允许表是唯一出网依据；对非允许目标的连接被阻断并留证据。
- **P4 产物证据链**：场景产物以 F 版本发布（bytes+sha256）；独立验收者从 R 登记与 F 引用直接核对，不依赖实现者陈述。
- **P5 动作留痕**：关键动作经 outbox（`.lore/emit-requests.jsonl`）进入 E，受既有 emit 行数/字节预算与前缀不可改写校验约束。
- **P6 内容不改变授权**：页面内容（含注入文本）不得改变授权、预算或工具面；Harness 停止/确认规则对页面诱导同样生效。
- **P7 故障语义不变**：浏览器进程崩溃/超时按既有 INCOMPLETE_OBSERVATION/UNKNOWN 语义处理，不重跑、不修补。

## 3. 用例

**批量 A（功能，固定响应批，M02 模式：真实 Runtime/Docker/NATS/F/S + 本地固定 HTTP 模型响应）**——每类 3 次：

- A1 单页读取：容器内静态页面 → 读取标题/状态 → 写产物文件 → F 版本核对。
- A2 状态变更操作：本地页面表单/点击 → 状态变化经产物核对。
- A3 多步导航：两页跳转 → 汇总产物。
- 通过：产物 sha256 与预期一致；R/F/X/E 记录完整；无契约违规事件。

**批量 B（负例，可与 A 同批）**：

- N1 越权出网：脚本访问非允许表目标 → 连接被阻断，证据含阻断事实与执行记录（P3）。
- N2 产物篡改：事后改动产物文件 → F/R 校验拒绝并留痕（P4）。
- N3 页面注入：固定响应中模型遵从页面文本指令执行额外动作 → Harness 公开停止，不得产生额外授权/执行（P6）。

**批量 C（真实模型批，后置）**：与 M01 预算修复同批或随后；2 类任务 × 3 次；判据必须区分 grounding/任务失败与环境失败，C 结果单独记录，不回填 A/B。

## 4. 判据与证据

每批次先预注册协议 JSON（问题、判据、样本量、停止条件），再产出原始证据：X 执行记录、F 版本及 manifest、R 决策与回执、E 事件、固定 HTTP 响应副本。独立验收者按证据指南直接核对产物并复跑代表性检查。批量 A/B 通过 = 对应性质获得层级匹配证据；未运行、跳过与失败均按原状记录。

## 5. 验证环境

Linux 容器运行时（`governance/linux-environment.md`）+ Docker + `linux-browser` profile 镜像（构建脚本与 digest 登记在案）；本地固定响应服务器沿用 M02 设施形态。宿主侧 Node/Pi 依赖树与物理身份 manifest 按现状要求在新环境重新生成（同 M01/M02 约束）。
