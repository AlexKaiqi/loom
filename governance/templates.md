# 任务资产记录模板

只为实际工作实例化必要模板，放在清楚命名的任务记录目录中。多个小项可以合并记录；通过条目必须链接到证据。以下全为空模板，不代表任何项目已通过。

## 1. 目标与范围基线

- 任务 / 基线版本 / 日期：
- 用户要求与设计来源：
- 当前授权工作、最终目标、非目标：
- 本阶段范围与全系统剩余范围：
- 必须项及优先级：
- 原始要求 ID → 性质 ID → 所属里程碑 → 验收证据（未有证据填 UNVERIFIED）：
- 已确认事实 / 假设 / 未知项 / 资料冲突：
- 完成条件与暂不纳入的事项及依据：

## 2. 性质与验收契约

- 性质 ID / 契约版本 / 建立时间（早于对应实现）：
- 关联原始要求与来源段落：
- 必须保证的行为、不变量及理由：
- 适用输入、状态、环境、依赖、故障与负载；明确不覆盖范围：
- 判据来源、独立预期或推导过程：
- 通过标准、误差、时限、采样方案（适用时；待定不能进入相关实现）：
- 正常 / 边界 / 相关失败用例与预期：
- 验证器应拒绝的已知错误或负对照：
- 验证代码、命令或操作步骤；直接观测点：
- 所需真实依赖、允许的替身及局限：
- 所需证据类型、输出位置、执行与验收责任：
- 当前状态 / 证据引用 / 限制与异议：

## 3. 判断、变更与取舍记录

- 决策 ID / 日期 / 关联目标与性质：
- 待解决问题与先前判断：
- 候选方案及证据；区分事实、假设、推断：
- 选择与否决理由；适用前提与重新评估条件：
- 若修改标准：旧标准 → 新标准；来自目标或外部事实的独立理由：
- 是否改变根本目标或必须范围；既有授权依据 / 未决事项：
- 影响的抽象、契约、实现、数据和证据；失效及重验安排：
- 保留的旧失败 / 旧证据引用：

## 4. 开源项目与组件调研记录

- 项目 / 实际仓库 / 固定提交 / 研究问题：
- 关联性质；职责和权威状态归属：
- 机制及源码/测试位置；维护方声明与实际观测分开：
- 相关可复现实验的契约、环境、步骤、结果与原始证据：
- 可复用模块/接口、适用前提、独立验证边界、适配缺口：
- 拟复用代码及依赖的使用条件核查：
- 采用 / 否决 / 待验证的结论与依据；未知项：

## 5. 验证批次与失败记录

- 批次 ID / 性质与契约版本 / 证据类型 / 声明范围：
- 批次用途：探索测量 / 正式验收；探索结果不得计作性质 PASS：
- 实现提交 + 未提交修改快照（如有）；验证脚本、数据与相关依赖版本：
- 环境、配置身份、工作位置、命令/步骤、时间及随机条件：
- 实际运行 / 跳过 / 未运行项；原因、退出状态、断言与负对照：
- 原始产物和日志位置；必要的完整性摘要：
- 预期 → 实际 → 状态与裁定理由：
- 失败 ID、最小复现、诊断假设、区分原因的实验、修复及回归批次：
- 验收者直接检查与独立复跑记录；异议、限制和后续动作：
- 对当前交付版本是否有效；证据复用或失效理由：

## 6. 阶段门槛记录

- 阶段 / 范围 / 当前版本：
- 适用 checklist 条目 ID → 状态 → 证据 → 裁定理由：
- 必须项失败、缺证据或阻塞；N/A 的原始范围依据：
- 审查者及直接检查记录：
- 可否进入下一层 / 必须回退到哪一层 / 下一步补证据工作：

## 7. 长任务恢复记录

- 最近更新时间 / 当前用户目标和授权：
- 正式目标、契约及决策索引；当前阶段与未过门槛：
- 必须保留的原则、非目标与约束：
- 已验证结论及当前有效证据：
- 当前代码/文件/依赖状态；未提交修改或未完成编辑：
- 失败、阻塞、未验证假设及证据失效项：
- 进行中的进程/任务、执行身份、外部效果和未决回执的查询方法：
- 下一步具体动作、关联性质、要获得的证据与停止条件：
- 当前阶段通过后自动继续的下一已授权阶段；整项任务的真正终点：
- 子任务范围、状态和交接产物；暂存但不属于当前范围的改进：

## 8. 最终独立验收报告

- 交付对象与准确范围；最终版本/快照：
- 原始要求 → 性质 → 必须用例 → 当前有效证据 → 裁定：
- 组件、组合、系统验证覆盖；未覆盖的原系统阶段：
- 验收者身份、判据来源、直接检查和独立复跑批次：
- 标准变更、旧失败及修复回归审查：
- 尚存异议、限制、未验证或阻塞项；是否阻止完成：
- 启动、复现验证和恢复方法；资产索引：
- 最终结论：本范围完成 / 未完成。理由必须来自逐项证据，不以计划、代码量或时间替代。

## 9. 可直接交给独立验收 Agent 的任务

从原始目标、性质契约和被验版本开始，独立确定应该满足的要求，再阅读实现者报告。逐项检查核心性质的直接证据、判据独立性、版本和范围匹配，特别检查负对照、跳过、mock、标准修改和旧证据复用。直接读取关键产物和原始记录，并在独立批次中复跑有代表性的核心检查。不要修改被验实现、预期和阈值；发现缺陷交回修复，再验新版本。报告每项状态、证据和异议。其他 Agent 的总结不能替代观测。验收依据已经确定的目标；新发现先区分现有要求遗漏、当前缺陷和范围外改进。证据充分时结束验收，不无理由追加工作。
