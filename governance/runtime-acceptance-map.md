# Harness Runtime 性质与独立验收映射

## 开发前仍须补齐

1. G0 的原始要求覆盖矩阵：此表是重点性质索引，不是 v5 所有细则的穷尽验收合同。逐项检查登记路径移动/删除/换绑定、输入完整性与可访问性、未登记或歧义目标拒绝且不回退宿主、推进中 Harness 版本不静默改变、截断或未完成请求不当作最终回答等细则是否已进入相应性质卡。
2. 每张性质卡的恢复边界、威胁范围、真实依赖和验证观测权限。涉及数值的场景先确定有依据的阈值；未知项不视为可跳过。
3. 顶层模型与模拟结果；候选技术的运行实验。当前没有任何项目采用结论。
4. 性质到具体用例、组件及证据批次的映射，以及 M 和 X 的正式里程碑覆盖。

演示样例中的 10 是来自 v5 的确定预期；本表其余测试细节是用于细化契约的候选方案，不能因写进表格就声称已经验证。
