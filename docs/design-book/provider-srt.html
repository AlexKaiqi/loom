SRT 官方库

接入前先核对 Provider 公共契约与任务执行契约。

SRT 官方库

SRT 为宿主进程生成文件和网络限制。Loom 通过受信 Node 适配进程使用官方库，负责操作身份、进程管理和结果保存；SRT 不提供跨重启的作业调度。

Loom 阶段实际接口／动作结果解释
Describe／就绪检查验证锁定 Node、SRT 包与平台依赖；校验上游配置 schema；真实运行受控探针包已安装不代表 Linux namespace／macOS 策略已获允许。探针也只证明它测试过的能力。
Acquire固定 Allocation 与工作根；准备完整配置，临时受信 Node 进程内调用 SandboxManager.initialize(config)取得受控执行范围，不创建虚拟机；独立配置保护不同 Work。
执行前准备按已验证的 Shell 参数引用规则编码 argv；wrapWithSandbox(command, …, {commandId, commandText})只有策略生成与验证完成才回报可启动；commandId 是诊断关联，不是上游持久执行 ID。
ExecuteRuntime 通过原子比较并交换（CAS）确认本次派发后，发放一次性启动许可，适配进程 spawn(wrapped,…)；子工具只继承 stdio 和明确允许项在独立受信通道报告 code／signal；原输出流不当控制消息解析。若初始化中会跑用户代码，必须单独有 Effect 和屏障。
保存／返回等待进程终态与流关闭，保存已取得字节，协调副本的稳定读取，再由 ContentPort 捕获并确认版本。任何非零结果都保留；不把适配器自身异常改写成任务 exit。清理失败不覆盖原结果。
Stop／Inspect／Release库清理使用 cleanupAfterCommand、reset；进程停止与核对使用原 identity 和公共执行组件。库未提供独立 durable job 查询。失联后只读已存结果、核对实际进程域；不重跑取日志。没有可靠证据不声称所有后代停止。
授权到上游字段的具体映射

获准读根、私有目录拒绝和可写副本分别映射为 SRT 的 filesystem.allowRead / denyRead / allowWrite / denyWrite；系统只读运行库和临时目录另由锁定工具链提供。按上游规则优先级限制默认读取范围，仅开放获准目录，并通过负向测试确认拒绝规则生效。网络映射为 network.allowedDomains / deniedDomains；无外联时 allowedDomains 为空。Loom 配置对象只构造上游公开 schema，不生成 SBPL 或手写 bwrap 参数。对不受支持的字段、路径和代理机制明确拒绝，按两平台负向测试核验实际效果。

SRT 管理实例持有配置状态，因此每次接入使用独立的临时 Node 进程，并复用发行包中的 Node 依赖。原生结果和控制消息分通道；不同 Work 不共享可变 SandboxManager。输入队列、持久调度和工作记录仍由 Runtime 管理。[S22]

// 受信适配器片段；不是完整执行器。authorize / CAS / capture 在 Runtime。
await SandboxManager.initialize(config);
const wrapped = await SandboxManager.wrapWithSandbox(
  encodedArgv, undefined, undefined, undefined,
  { commandId: effectId, commandText: displayCommand }
);
// 等 Runtime 的本次有效的派发许可，才允许 spawn。
await waitForCurrentDispatch();
const child = spawn(wrapped, {
  shell: true, cwd: trustedCwd, env: sanitizedEnv,
  stdio: ["pipe", "pipe", "pipe"]  // 不继承适配器控制 FD
});
