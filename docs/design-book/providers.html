A.5 执行后端接入

本组接入页说明每种执行后端如何取得环境、执行命令、查询原操作和保存内容。上游 CLI／SDK 的调用封装在各自适配器内；目录、凭据和实例身份来自 Runtime 已确认的绑定。后端缺少所需能力时，适配器须明确拒绝。

接口说明以来源页记录的研究版本为依据。部署时须锁定实际版本，并验证接口、权限和故障行为；这些页面不构成已完成接入的证明。
