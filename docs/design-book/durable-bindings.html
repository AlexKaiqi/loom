A.3 Durable 组合与接口边界

组合 作者入口 执行权威 还需由 Loom 衔接
T：Temporal Workflow／Activity；公共作者库封装领域操作。 Temporal History、输入状态、Timer 和 Task Queue。 请求内容绑定、输入关联、原操作核对、内容保留、授权、预算、业务历史读取。
E：DSH／Cordis + 可嵌入内核 明确领域状态与有限推进；Cordis 管活动实例。 选定内核的一份控制状态与责任记录。 DSH 事件／投影／检查点的适配、冷工作调度、阶段提交、操作收据；不另留可独立推进的 JSONL 权威。
R：Resonate 固定 SDK 的受管 run／rpc／sleep 和组合子。 协议的 promise／task 与执行状态。 同键改内容检查、输入邮箱、订阅关联、结果未知与取消分层、预算和长期记录。

T 的实际运行位置

Temporal Service 保存历史和安排任务；自己的 Workflow Worker 运行 Harness，Activity Worker 运行模型／内容／执行接入。两种 Worker 角色可同进程或分部署，不是一 Work 一进程。相同队列须具有相容代码和实际资源访问能力；队列名不授予文件权限。

proxyActivities 安排标准 Activity；Worker 取得任务后通过受信 Runtime 端口访问 pi-ai、内容库或 Provider，保存结果再报告完成。Workflow 不绕过 Activity 裸读可变文件。Model Activity 只有单次供应商调用，不内置 Agent loop。

Loom 动作 T 的映射与确认
启动 StartWorkflow，固定 Work／release／配置。禁止复用已关闭 Work 身份。
输入／控制 短 loom.input／loom.control Update；COMPLETED 才形成相应回执。handler 必须先安装，初始化未完成时返回 not_ready。
next／complete Workflow 状态保存队列、处理身份、等待与处置；返回 delivery 的选择是已记录控制决定。
单次操作 一个稳定 operation_id 对应已固定请求；Activity 重入查询原收据，而非重发原命令。
Timer 原生 Timer + 计划状态；到期、取消与输入登记由同一控制顺序裁决。
运行滚动 等 handler 完成，固定输入、回执、订阅与关闭标记、计划、未结操作和代码版本，再 Continue-As-New。
状态读取 Query 为应用当前状态；Describe 为引擎状态；历史读取通过官方 API + 内容引用。离线视图注明水位。
关闭／清理 最终受理／处置快照可读；独立清理任务被持久接管后，慢回收不要求原 Harness 常驻。

跨 Run 去重不能清空 seen 集合。可将旧回执和订阅关闭标记封存为不可变索引、当前 Run 保留增量；加载失败不等于没有该输入。运行历史的保留期限必须覆盖导出与恢复要求，否则不可宣称完整历史长期可读。

T 的模型／内容 TS Worker 通过受信 JSON-RPC 连接 Go Runtime 的 ContentPort／OperationPort；Sandbox Go Activity 可直接调用 Provider。认证、部署、converter、资源范围均固定；Node 类实例和 SDK 私有异常不成为 wire 类型。消息依据；重放依据。

E 与 R 的重点验证接缝

E 复用 DSH 的语义事件、状态投影和检查点思想，持久确认必须位于派发之前；恢复中断的消息关系不代表原业务输入已经处理完成。无 Agent 在线时的到期与输入接续由共享内核承担，不挂在 Cordis Fiber 存活上。

R 的 durable promise 表示可等待的返回值，Task 表示计算责任，Effect 记录外部动作与证据。原 Promise 终态不覆盖真实操作的迟到结果。原生 task fencing 约束协议状态，不自动限制外部进程写入。状态机研究入口。

两条候选都必须完成 E01—H01 的同一组轨迹，才能评价是否保持相同契约；不能凭接口名称相似计为兼容。
