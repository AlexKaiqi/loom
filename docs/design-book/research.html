B.1 已采用的分工与候选

对象 学习／使用什么 边界与判断
NATS／JetStream 持久发布、离线消费、积压与重投。 现有事件实现；目标业务受理和处理不是 NATS ACK。
Temporal 控制流重放、Activity、消息、Timer、任务安排。 参考组合 T；不强制所有 Harness 采用它的源码形式。
DSH 模型访问与 loop 分离；工具管线；语义事件、投影、检查点。 不将 minimal 配置误当全部宿主能力，也不照搬完整产品或旧 Loom 状态映射。
Cordis 依赖、scope、注册和临时实例装卸。 可用于组合宿主；不排除它，也不要求所有 Harness 使用。
Resonate 受管 async、promise／task 协议、可执行规范和轨迹检查。 完整候选 R；需核对内容绑定、等待、取消和 Effect 的语义差异。
Durable Task／Dapr 可嵌入执行内核、任务完成与后续责任交接。 候选 E；抽取内核不自动继承完整部署的所有保证。
DBOS／LangGraph 库式执行、步骤记录、部分结果与检查点。 作为完整路径比较；状态可恢复不自动代表冷 Work 可被主动唤醒。
pi-ai 单次模型供应商适配。 不接入强制循环或隐式上下文裁剪。
Git／不可变 records／SQLite 视图 内容版本、原文字节、固定范围查询。 具体权威由执行组合声明；读取面不平行决定下一步。

DSH 研究按能力接口、实现和消费者分离进行借鉴，重点包括 ctx.llm、Session／Persistence／Checkpoint、工具管线及状态所有权。架构依据、模型服务、循环、上下文。逐包数量、旧代码行数与旧版本优劣结论不作为 Loom 契约。

B.2 Provider 选择理由

SRT 提供原生用户级进程管控；Apple container 和 rootless Podman 提供本机独立任务环境；OpenSandbox 提供自部署路径；Cloudflare Bridge 与 E2B 提供云端路径。共同接口不宣称操作系统、隔离强度和命令恢复能力相同。

apple-sandbox 的薄 CLI、宿主目录挂载和日志保留值得学习；通用适配直接使用 Apple container，不引入其 OpenAI 会话入口。OpenAI 独立执行仍按已核对资料限定为研究项。未选择的直接内核 API、自建容器管理器和其他工具，不因存在就加入默认依赖；具体能力出现后按相同契约比较。

B.4 文档检查

原稿附带的工作模型 0.1 报告记载了 74 项参考测试和 96 种有限交错。两种持久表示共用状态转移函数，模型及传输使用测试替身；本次未重新运行该实验，不将其计为新增作者接口或实际后端验收。

本次文档构建检查

内部链接与对象 ID 校验通过；8 段 JSON、5 段 TOML 解析通过；Event／Input 与 Model 接口声明及 4 段正文 TypeScript 示例通过严格类型检查，业务辅助函数仅以类型声明参与。

Chromium 渲染检查覆盖 1440px 桌面与 390px 移动端、折叠内容深链接及全部 10 个图示放大入口。页面无脚本报错、无外部资源请求，图中文字未超出 SVG 范围。测试环境以 HTML 内容加载进行渲染；未进行实际引擎、模型、权限或故障执行验收。

外部引擎、模型服务、Sandbox、权限与故障恢复未因本次文档校订获得新的通过状态。新增事件作者契约需要真实输入桥、跨 Run、退订竞争和模型使用验证。
