E2B SDK

E2B 用于接入托管沙箱。适配器在受信 Node 进程中调用官方 e2b JavaScript SDK，由 SDK 处理 envd/Connect 协议；Harness 的推进逻辑仍在 Loom 一侧。API key 保留在受信适配器，不进入任务环境。SDK、模板和 envd 版本均随部署固定。[S38]

Loom 阶段官方 SDK 对应入口映射要求
AcquireSandbox.create(...)；记录 sandboxId 和实际环境模板与 metadata 由受信部署选择。metadata 不等于创建幂等；创建回执丢失先按原账号和 metadata 核对，未确认不再 create。
Inspect / 重连Sandbox.getInfo(id)／实例 getInfo()；获准接续才用 Sandbox.connect(id)getInfo 属于只读信息获取；connect 对 paused 环境可能 resume 并延长 TTL，不能当作纯查询。原环境失效后不得对同名新环境重做原命令。
Executesandbox.commands.run(command, {cwd, envs, timeoutMs, ...})官方样本将 command 交给 /bin/bash -l -c。按已验证的 Shell 参数引用规则把 Loom argv 编码为 shellText，原 argv 与实际命令均记录；模板启动文件必须受信，不把字符串接口写成 native argv。
执行引用 / 输出内部可用 background:true 先取 CommandHandle，再 wait()；onStdout / onStderr这是适配器提早取得执行引用的方式，不向模型放开脱离监督后台任务。PID + sandbox + 原运行世代共同绑定；一取得就保存。
原命令连接 / 停止commands.list()、commands.connect(pid)、commands.kill(pid)文档／源码提供运行中命令连接，不等于无限历史输出重取。PID 单独不足以授权停止；缺原世代或已重建时不能试探性 kill。
内容files.write / files.read；已有平台卷能力独立验证transfer 使用文件 API；选择平台持久卷时单独验证其保存与读取语义。SDK 返回不替代内容引用提交；保存完才允许删除环境。
Releasesandbox.kill()／静态 kill 原 ID只影响原分配；生命周期 timeout、pause、resume 和内容保留分别记录。pause 不是终止，不能当作永久写能力撤销。

E2B 接入参考固定源码 ccaf9fc0ffe6ac39c7ec786af7608ab1de19467b。发布前须验证并固定 SDK 与服务组合，覆盖启动回执丢失、命令连接中断、迟到输出、文件保留和原对象停止。
