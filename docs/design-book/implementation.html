附录 A. 实现接入与配置

本附录面向 Runtime 和适配器的实现者，说明如何用具体组件落实前文契约。事件服务选择 NATS／JetStream；持久执行以 Temporal 为参考组合 T，另比较 DSH／Cordis 与可嵌入内核的组合 E，以及 Resonate 组合 R。每个 Work 只能由一套选定的执行状态决定如何恢复，不能让多个引擎各自推进。

先查作者接口与编码，再按所选执行组合和 Provider 阅读接入页。示例描述目标接法；是否已实现、支持哪些运行和故障场景，须由对应版本的验收报告确认。
