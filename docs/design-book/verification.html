09. 运行与契约验收

9.1 管理入口

管理动作 确认语义
注册／启动 Work 固定工作身份、配置、Harness release 与初始输入；重复请求取得原结果。
查询 返回生命周期、未处理输入、在途操作、等待、预算和内容引用；离线视图标水位与陈旧性。
暂停／继续 暂停新业务推进，仍保存输入和真实结果；继续原责任。不是回拨历史。
关闭 停止新准入，处置输入和计划，完成／取消／转交操作与清理后关闭。
Fork 新身份、新授权检查、确定来源；不删除原工作或继承未知操作重放权。

Runtime 启动先验证存储、部署与能力绑定，再恢复未结责任和订阅；停机先停止新的派发，保存／交接在途责任。工作存在不要求创建专属进程。多节点接管、断电与存储丢失需分别声明支持范围。

9.2 可执行判据

编号 测试轨迹 必须观察到的结果
E01 登记订阅，卸载 Harness，期间发布，再恢复。 同一订阅保留原起点，目标自动取得事件。
E02 事件先到、next 后调用；或检查空队列与休眠之间到达。 不漏输入，不需第二条消息触发。
E03 重投、两份重叠订阅、两个不同 Work。 同 Work 一个输入，不同 Work 各一个；改内容冲突。
E04 next 后退出；发布结果后、complete 前退出。 原处理继续，原发布复用，不重复逻辑结果。
E05 退订与交付竞争，退订后仍有排队输入。 以目标准入顺序仲裁；保留已受理项，排空后等待结束。
E06 起点过期、内容缺失、撤权、过载。 明确拒绝或等待及证据，无静默跳过和假成功。
D01 输入已确认、执行前退出。 自动继续，不靠用户逐项运维。
D02 结果／内容已保存、回执丢失。 取得原收据，不重做已确认操作。
D03 外部可能成功但无回执；取消后有迟到结果。 原对象核对；取消、停止与结果各自保存。
D04 定时到期、提前答复、跨运行历史滚动。 等待不丢；拒绝结束等待但不授权动作。
D05 Archive 保存中退出；旧批准遇到新内容版本。 无半归档；旧批准不用于新版本。
M01 无 Agent loop 直接批量调用；37/100 完成后退出。 独立结果和上下文，按原项目身份接续。
M02 并发逼近预算、用量未知、schema 不支持。 原子准入、未知不当零、不静默降级。
S01 shared／transfer；Shell 退出但后代仍写；释放失败。 稳定内容才确认，阻止冲突写入，清理不覆盖结果。
H01 Basic 换 Worksurface、增加验证或更换版本。 只改对应策略；共享输入、操作和恢复契约保持。

9.3 证据范围

模型测试、组件测试、真实组合和产品验收分层记录。每份报告绑定源码、依赖、配置与故障范围；失败／跳过／未验证不计为通过。本文定义目标契约，不据接口映射宣称后端符合。

参考模型、真实组件与完整组合的证据分开保存；本书不将一份参考测试报告推广为所有后端的符合性证明。检查范围见附录 B.4。
