OpenSandbox SDK／API

接入前先核对 Provider 公共契约与Sandbox 作者契约。

OpenSandbox SDK／API

接入官方 Go SDK 或由锁定 OpenAPI 生成的客户端，服务端仍由原部署管理。生命周期地址、Execd 端点与认证、Egress 能力分别解析；不假定 8080 管理密钥可以访问所有执行端。远端 hostPath 指服务器路径，绝不把 Mac／Linux 客户端路径直接放过去。[S23]

Loom 阶段上游接口映射要求
AcquireLifecycle POST /v1/sandboxes；GET /v1/sandboxes/{id}创建请求持久关联，元数据保留 Loom key；metadata 查询不自动证明创建幂等，未知先核对。实际 image/platform/volumes/network/timeout 各自锁定。
执行通道 ReadyGET /v1/sandboxes/{id}/endpoints/{port}，再 GET /ping使用返回地址及其所需 headers（如 X-EXECD-ACCESS-TOKEN）；原效果始终使用其固定端点与环境身份。
ExecuteExecd POST /command，SSE 结果核对样本支持 command 与 argv 二选一；优先字面 argv，cwd/envs/timeout 显式传递。禁用不安全重试。background 不因上游支持而默认开启。
Inspect／StopGET /command/status/{id}；DELETE /command 按原协议 ID命令 ID 一取得即保存；中断请求不是停止完成。GET /command/{id}/logs 的样本说明是后台命令日志，不对前台流自动承诺完整补取。
文件POST /files/upload 与 GET /files/download；或预配置获准持久卷只在 transfer 路径调用；Range/上传重试按真实幂等规则。暂停环境后 execd 可能不可用，必须有其他可读稳定来源或先完成应用静止，不能写出互相阻塞的时序。
网络／回收GET/PUT/PATCH /v1/sandboxes/{id}/networkpolicy；DELETE /v1/sandboxes/{id}验证实际 Egress 规则；资源删除前保存必要文件。TTL 与续租操作具有稳定身份和结果记录，结果收集与资源到期分别管理。
{
  "argv": ["python3", "-c", "print('hello')"],
  "cwd": "/workspace",
  "envs": {"PYTHONUNBUFFERED": "1"},
  "timeout": 120000,
  "background": false
}

命令载荷按锁定 API 的 schema 验证；适配器核验 argv 支持及 cwd 的变量／~ 展开行为。Loom 根映射使用字面路径，存在歧义时拒绝。必要字段或内容能力缺失时不开放对应操作；isolated diff/commit 等上游能力必须有独立证据，不能推定为内容确认。 [S23]
