让复杂工作
持续推进。

Harness 决定如何取得信息、采取行动和检验结果，也可以在运行中生成并调用另一个 Harness；Runtime 持续保存调用责任、等待和恢复依据，让工作不依赖某个进程一直在线。

本书先定义目标契约，再说明实现与拼接。示例 API 与配置不表示已经发布；实际可用范围以对应版本的实现说明和验证报告为准。

从目标与范围开始，理解 Harness 和 Runtime 的分工。编写 Harness 时查工作契约与示例；实现 Runtime 时，按事件、持久执行和 Harness 执行管理进入实现与拼接；用户环境由 Sandbox 完整提供，Loom 维护消费与工作接合。具体规则只在所属分篇维护。
