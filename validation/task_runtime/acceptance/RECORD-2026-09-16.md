## 最终判定

**A（收尾原话）**：CONVERGED for the WHOLE deliverable（runtime + 校验资产）。六轮里每一个 runtime 失败（A 系列、N1–N10）与每一个校验资产缺陷（R1/R2/R5/R6/R7/R8）都已"修复并被独立复现通过"，或"明确接受为政策/已知缺口"；它再也构造不出任何能弄砖任务或丢失已提交事实的 payload、尾部形状、ledger 损坏或恢复故障。

**B（收尾原话）**：检查器缺陷修复成立（补换行篡改现在 FAIL、干净证据保持全绿、逐字节矩阵只有 `b"sum=10"` 通过）；真实模型新任务 8.68s 通过；篡改能被抓；ask-user 零驻留；**未发现 runtime 反例**。

## 六轮发现与处置（摘要）

| 类别 | 发现 | 处置 |
|---|---|---|
| 耐久 | `recover` 非原字节 | 按行切原字节 |
| 耐久 | **commit 行已写、head 未推进** → 丢已提交事实、卡死 | `run_round` 拒绝开轮；`recover` **补发布** commit |
| 安全 | **复制任务目录继承跨任务授权** | 授权改 host 侧登记（`<root>/.lore-authority.json`），副本一律拒绝并留痕；`register` 支持显式收养 |
| 耐久 | 撕裂尾行污染下一次写入 | 写前修复 + 精确字节留痕；三种形状（非法行 / 合法缺换行 / 完好）分别处理 |
| 耐久 | **双重 `recover` 删掉已受理事实** | `recover` 仅在最后一行是 `start` 时动作，否则 no-op；abort 行带 commit floor |
| 耐久 | 换行结尾的畸形行不被检查 | 检查"最后一个非空行"，与是否带换行无关 |
| 耐久 | 中段损坏静默丢事实 | `read_facts` 响亮报错（物理行号），文件字节不动 |
| 耐久 | **Unicode 行分隔符（U+2028/2029/0085）把合法记录读崩** | JSONL 只按 `\n` 切（runtime、ledger、校验器、recall 行号统一） |
| 契约 | `layout_version>1` 静默接受 | 响亮拒绝 |
| 契约 | 声明的 role/contract/view digest 不比对 | 逐项比对，不符即拒 |
| 契约 | `start` 行缺 `trigger_seq` → KeyError | 显式拒绝，不猜 commit floor |
| 授权 | 直接 `ingest` 绕过跨任务授权 | kind 可声明 `requires_relation`；`task.delegated`/`task.reported` 已标 |
| 校验器 | `.strip()` 假精确 | 字节精确（B 复验） |
| 校验器 | `independent_recall` 仍用 `splitlines()`（我的说法超出证据） | 改为 `split("\n")`；全仓库仅剩注释 |
| 不对称 | `ledger.read_jsonl` 损坏行静默 break | 响亮报错；补 U+2028 行往返用例 |

## 当前证据状态

- 离线：**180 断言 / 11 用例，0 失败**（连跑两次逐行一致）。
- 真实模型：9/9 场景有 ark 运行 + 独立校验器 `ok: true`（goal 13、plan 12、archive 11、ask-user 9、coding 14、monitoring 8、research 17、system-design 14、delegation 16，均为 fresh==saved）。
- 凭据：扫描 1771 个非 `.git` 文件，密钥值**零命中**。

## 验收明确接受、未修复的边界（不得当作通过）

1. **R3**：`requires_relation` 逐 kind 手工声明，无审计（自动推断等于用猜测替代契约）。
2. **R4**：并发 `recover`/单写者无租约——契约本就列明的缺口。
3. **N4**：`<root>/.lore-authority.json` 同 UID 可写即可伪造——**不是安全边界**；真防护需密钥/身份（PKI）。
4. **角色分离有限**：同机同工作区、由实现会话派出；`lore_task/`、`lore_harness/` 未提交，**无 commit 版本钉**。
5. **真实模型证据按产物复核**，未做网络复跑（模型来源不可独立重现）。
6. 未验证：`derived/` 重建、真实沙箱隔离（Workspace 只有路由与记账）、L2 未知条目保真、任意切点崩溃注入。
7. **孤立代理项（lone surrogate）payload** 会让轮以 `UnicodeEncodeError` 中止（可 `recover`，非弄砖），当前是 traceback 而非类型化拒绝——记为后续项（backlog B17），**为保持"被验收版本 = 交付版本"未在验收后改动**。
